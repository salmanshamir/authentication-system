# 🔐 Flask-AuthSystem

A secure and modern authentication system built with Flask, featuring email verification, Google OAuth, session management, and user profile management.

## ✨ Features

- 🔑 User Registration & Login
- 📧 Email Verification with OTP
- 🌐 Google OAuth Authentication
- 🔒 Secure Password Hashing with Werkzeug
- 🛡️ Session Management
- 👤 User Profile Management
- 🖼️ Profile Image Upload
- 🎨 Responsive Authentication Interface

## 🚀 Getting Started

```bash
git clone https://github.com/salmanshamir/Flask-AuthSystem.git

cd authentication system

python -m venv venv

pip install -r requirements.txt

python app.py
```

Configure your environment variables in `.env` before running the application.
